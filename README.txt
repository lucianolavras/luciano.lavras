SITE PESSOAL — LUCIANO LIMA

1. Abra index.html no navegador.
2. Para usar sua foto principal, coloque a imagem na pasta assets com o nome luciano.jpg e substitua no index.html o bloco class="photo-placeholder" por:
   <img src="assets/luciano.jpg" alt="Luciano Lima" class="photo-placeholder">
3. Edite a seção Contato no index.html para inserir e-mail, WhatsApp, Instagram, LinkedIn e GitHub.
4. Os cards de Projetos estão preparados para receber nomes, descrições, imagens e links.
5. Para publicar, envie toda a pasta para sua hospedagem.
